# SpecBridge benchmark v0.3 results

## Status

Preliminary: generated from saved artifacts; no claim is made until all configurations have complete repetitions and human adjudication.

## Research question

Does multi-agent debate improve detection of explicit product-requirement violations enough to justify cost, latency, and false positives?

## Limitations

This is a 10-case controlled benchmark from one reference SaaS environment, created by the same team as its evaluator. Results may be sensitive to prompts, models, randomness, and matching rules; three repetitions remain a small sample. It measures requirement-violation detection, not general code-review quality. Interpret comparisons as directional, not universal.

## Reproduction

Run the consolidated CLI in dry-run mode first:

```bash
pnpm exec specbridge bench validate --benchmark v0.2
pnpm exec specbridge bench experiment --all --dry-run
```

For an offline fixture rehearsal, use `pnpm exec specbridge bench experiment --all --fixture perfect --output-dir results/benchmarks/v0.3/runs`. For an explicitly authorized live run, replace `--fixture perfect` with `--live` and provide the required provider environment. Then score and report the saved runs:

```bash
pnpm exec specbridge bench experiment-score --runs results/benchmarks/v0.3/runs --output results/benchmarks/v0.3/automatic-results.json
pnpm exec specbridge bench experiment-report --scores results/benchmarks/v0.3/automatic-results.json --output-dir results/benchmarks/v0.3
```

Raw run files remain under `results/benchmarks/v0.3/runs/`.
