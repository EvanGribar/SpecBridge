# What's new in 0.4.0

A clear summary of the changes included in this release.

### Consolidated benchmark surface

The CLI now exposes offline review, deterministic scoring/reporting, experiment, and change-mode evaluation through `specbridge bench`. Provider-backed reviewers remain an explicit opt-in via `@specbridge/benchmark-adapters`.
